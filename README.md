# Keshav Agrawal's Portfolio

A minimal, modern, and high-performance portfolio showcasing full-stack web applications, distributed systems, and AI/ML projects built with Next.js 15, TypeScript, and Tailwind CSS.

---

## 🏆 Featured Projects

1. **ClassMate**: All-in-one full-stack campus management platform with attendance tracking (ClassPulse), P2P skill exchange (SkillSwap), internship aggregator, and carpooling.
2. **HydraCache**: Decentralized, fault-tolerant in-memory distributed key-value store built in TypeScript with 64-bit Murmur3 consistent hashing, SWIM gossip, and HLC Last-Write-Wins.
3. **DocSaarthi**: AI-powered multilingual document intelligence platform engineered for Hindi, Devanagari, and English documents with PaddleOCR v4, hybrid search (pgvector + pg_trgm), and conversational RAG.
4. **ChatSphere**: Full-stack real-time communication platform supporting 1-on-1 and group chats, WebRTC audio/video calling, and Socket.IO messaging.
5. **Equity Nest**: Real-time Indian stock market analytical trading SaaS with live Upstox binary WebSocket feeds, TradingView charts, and in-memory NSE symbol fuzzy search.
6. **Luminary AI**: AI-powered academic planning platform for university discovery, admissions guidance, and ROI calculators.
7. **FreshFinds**: Local food waste reduction and marketplace connecting local vendors with nearby customers.
8. **Agricare**: Full-stack agricultural platform with digitalized inventory management, dynamic marketplace, and multi-language support (i18n).
9. **Heart Disease Predictor**: Deep neural network web app predicting cardiovascular disease risk.
